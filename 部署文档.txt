================================================================================
        农产品质量安全追溯与分析系统 - 完整部署文档
================================================================================

【文档说明】
本文档面向用户详细介绍如何从零开始部署和运行本系统。
请严格按照步骤操作，每一步都有详细说明。

【系统简介】
本系统是基于大数据技术的农产品质量安全追溯系统，可以：
- 追溯农产品从种植到销售的全流程
- 分析农产品质量数据
- 生成风险预警
- 可视化展示统计数据

【技术栈】
- Hadoop HDFS：分布式文件存储
- Apache Hive：数据仓库
- Apache Spark：数据分析
- MySQL：元数据存储
- Flask：Web后端
- Echarts：前端图表

================================================================================
                        第一部分：环境准备
================================================================================

【重要提示】
您只需要安装 2 个软件：Docker Desktop 和 Python
不需要单独安装 MySQL、Hadoop、Hive、Spark 等，它们都在 Docker 容器中运行！

--------------------------------------------------------------------------------
步骤 1.1：检查电脑配置
--------------------------------------------------------------------------------

最低配置要求：
- 操作系统：Windows 10 64位 专业版/企业版/教育版（家庭版需额外设置）
- 内存：8GB 以上（推荐 16GB）
- 硬盘：至少 20GB 可用空间
- CPU：支持虚拟化技术（Intel VT-x 或 AMD-V）

检查方法：
1. 按键盘 Win + R 键，打开"运行"对话框
2. 输入 msinfo32，点击"确定"
3. 在打开的窗口中查看：
   - 系统类型：应显示"x64"
   - 已安装的物理内存(RAM)：应大于 8GB

--------------------------------------------------------------------------------
步骤 1.2：启用 Windows 虚拟化功能
--------------------------------------------------------------------------------

【此步骤非常重要，Docker 需要虚拟化支持】

方法一：通过控制面板启用（推荐）

1. 点击屏幕左下角的 Windows 图标（开始菜单）
2. 输入"控制面板"，点击打开
3. 点击"程序"
4. 点击"启用或关闭 Windows 功能"
5. 在弹出的窗口中，找到并勾选以下选项：
   [√] Hyper-V
   [√] 适用于 Linux 的 Windows 子系统
   [√] 虚拟机平台
6. 点击"确定"按钮
7. 等待安装完成
8. 点击"立即重新启动"重启电脑

【注意】如果找不到 Hyper-V 选项，说明您的 Windows 是家庭版，
请参考文档末尾的"附录A：Windows 家庭版处理方法"


--------------------------------------------------------------------------------
步骤 1.3：下载并安装 Docker Desktop
--------------------------------------------------------------------------------

【Docker 是什么？】
Docker 是一个容器化平台，可以让我们在一个"容器"中运行各种软件，
而不需要在电脑上逐个安装。本系统的 Hadoop、Hive、Spark、MySQL 
都运行在 Docker 容器中。

【下载 Docker Desktop】

1. 打开浏览器（推荐使用 Chrome 或 Edge）

2. 访问 Docker 官网下载页面：
   https://www.docker.com/products/docker-desktop/
   
   或者使用国内镜像（下载更快）：
   https://mirrors.aliyun.com/docker-toolbox/windows/docker-for-windows/

3. 点击"Download for Windows"按钮下载
   文件名类似：Docker Desktop Installer.exe
   文件大小约：500MB

4. 等待下载完成（根据网速，可能需要 5-30 分钟）

【安装 Docker Desktop】

1. 找到下载的安装文件（通常在"下载"文件夹中）
   文件名：Docker Desktop Installer.exe

2. 双击运行安装程序

3. 如果弹出"用户账户控制"窗口，点击"是"

4. 在安装界面，保持默认选项：
   [√] Use WSL 2 instead of Hyper-V (recommended)
   [√] Add shortcut to desktop
   点击"OK"按钮

5. 等待安装完成（约 2-5 分钟）
   进度条会显示安装进度

6. 安装完成后，点击"Close and restart"按钮
   电脑会自动重启

【首次启动 Docker Desktop】

1. 电脑重启后，桌面上会出现 Docker Desktop 图标（一只鲸鱼）

2. 双击 Docker Desktop 图标启动

3. 首次启动会弹出服务条款窗口：
   点击"Accept"接受条款

4. 可能会弹出教程窗口，点击"Skip tutorial"跳过

5. 等待 Docker 启动完成：
   - 右下角任务栏会出现 Docker 图标（鲸鱼图标）
   - 图标颜色变为绑色表示启动成功
   - 首次启动可能需要 2-5 分钟

6. 验证 Docker 是否正常运行：
   - 右键点击任务栏的 Docker 图标
   - 如果显示"Docker Desktop is running"表示正常

【常见问题处理】

问题1：提示"WSL 2 installation is incomplete"
解决：
1. 访问 https://aka.ms/wsl2kernel
2. 下载"WSL2 Linux 内核更新包"
3. 双击安装
4. 重启 Docker Desktop

问题2：Docker 图标一直是黄色/橙色
解决：
1. 等待几分钟，Docker 正在启动
2. 如果超过 10 分钟还是黄色，重启电脑再试


--------------------------------------------------------------------------------
步骤 1.4：下载并安装 Python
--------------------------------------------------------------------------------

【Python 是什么？】
Python 是一种编程语言，本系统的 Web 应用（Flask）使用 Python 开发。
您需要安装 Python 来运行 Web 界面。

【下载 Python】

1. 打开浏览器

2. 访问 Python 官网：
   https://www.python.org/downloads/
   
   或者使用国内镜像（下载更快）：
   https://mirrors.huaweicloud.com/python/

3. 点击"Download Python 3.x.x"按钮（x.x 是版本号，选最新的即可）
   推荐下载 Python 3.10 或 3.11 版本
   文件名类似：python-3.11.x-amd64.exe

【安装 Python】

1. 找到下载的安装文件，双击运行

2. 【非常重要】在安装界面底部，勾选：
   [√] Add Python 3.x to PATH
   
   这一步非常重要！如果忘记勾选，后面会出错！

3. 点击"Install Now"开始安装

4. 等待安装完成（约 1-2 分钟）

5. 看到"Setup was successful"表示安装成功

6. 点击"Close"关闭安装程序

【验证 Python 安装】

1. 按键盘 Win + R 键，打开"运行"对话框

2. 输入 cmd，点击"确定"，打开命令提示符

3. 在黑色窗口中输入以下命令，然后按回车：
   python --version

4. 如果显示类似"Python 3.11.x"的版本号，表示安装成功

5. 再输入以下命令验证 pip（Python 包管理器）：
   pip --version

6. 如果显示类似"pip 23.x.x"的版本号，表示正常

【如果提示"python 不是内部或外部命令"】

这说明安装时没有勾选"Add Python to PATH"，解决方法：

方法一：重新安装 Python
1. 在控制面板中卸载 Python
2. 重新运行安装程序
3. 这次一定要勾选"Add Python to PATH"

方法二：手动添加环境变量
1. 右键"此电脑" -> 属性 -> 高级系统设置
2. 点击"环境变量"
3. 在"系统变量"中找到"Path"，双击
4. 点击"新建"，添加 Python 安装路径，例如：
   C:\Users\你的用户名\AppData\Local\Programs\Python\Python311\
   C:\Users\你的用户名\AppData\Local\Programs\Python\Python311\Scripts\
5. 点击"确定"保存
6. 重新打开命令提示符验证

--------------------------------------------------------------------------------
步骤 3.1：确保 Docker Desktop 正在运行
--------------------------------------------------------------------------------

【检查 Docker 状态】

1. 查看屏幕右下角的任务栏（时间旁边的小图标区域）

2. 找到 Docker 图标（一只鲸鱼背着集装箱的图标）

3. 检查图标状态：
   - 绿色：Docker 正在运行，可以继续下一步
   - 黄色/橙色：Docker 正在启动，请等待变绿
   - 红色：Docker 出错，需要重启
   - 找不到图标：Docker 未启动

【如果 Docker 未启动】

1. 双击桌面上的"Docker Desktop"图标

2. 等待 Docker 启动（1-3 分钟）

3. 直到任务栏图标变为绿色

【如果 Docker 图标是红色】

1. 右键点击 Docker 图标
2. 选择"Restart"重启 Docker
3. 等待重启完成

--------------------------------------------------------------------------------
步骤 3.2：一键启动系统
--------------------------------------------------------------------------------

【启动方法】

1. 打开项目文件夹（例如：D:\农产品追溯系统\）

2. 找到"启动.bat"文件

3. 双击"启动.bat"文件

4. 会弹出一个黑色的命令行窗口

5. 窗口中会显示启动进度，请耐心等待

【启动过程说明】

启动过程大约需要 3-10 分钟（首次启动较慢），您会看到以下信息：

========================================
  农产品质量安全追溯与分析系统 - 启动
========================================

[1/4] 检查Docker是否运行...
Docker运行正常！

[2/4] 正在构建并启动Docker容器...
（这一步首次会下载镜像，需要较长时间）

[3/4] 等待服务启动（约90秒）...
请耐心等待，Hive初始化需要一些时间...

[4/4] 检查服务状态...
（会显示所有容器的运行状态）

========================================
  Docker服务启动完成！
========================================

正在启动Flask Web应用...
启动后请访问: http://localhost:5000

【首次启动特别说明】

首次启动时，Docker 需要下载以下镜像（约 5GB）：
- mysql:5.7（约 500MB）
- apache/hadoop:3（约 2.5GB）
- apache/hive:4.0.0（约 2.5GB）
- apache/spark:3.5.0（约 1.5GB）

下载速度取决于您的网络，可能需要 10-30 分钟。
后续启动不需要重新下载，会快很多（约 2-3 分钟）。

【启动成功的标志】

当您看到以下信息时，表示系统启动成功：

 * Running on http://127.0.0.1:5000
 * Running on http://xxx.xxx.xxx.xxx:5000

此时可以打开浏览器访问系统了！

================================================================================
                        第四部分：停止系统
================================================================================

--------------------------------------------------------------------------------
步骤 4.1：停止 Web 应用
--------------------------------------------------------------------------------

【方法一：关闭命令行窗口】

1. 找到运行"启动.bat"的黑色命令行窗口

2. 直接点击窗口右上角的 X 按钮关闭

【方法二：使用快捷键】

1. 点击命令行窗口使其获得焦点

2. 按键盘 Ctrl + C 组合键

3. 如果提示"终止批处理操作吗(Y/N)?"，输入 Y 并回车

--------------------------------------------------------------------------------
步骤 4.2：停止 Docker 容器
--------------------------------------------------------------------------------

【方法一：双击停止脚本（推荐）】

1. 打开项目文件夹

2. 双击"停止.bat"文件

3. 等待所有容器停止

【方法二：手动停止】

1. 按 Win + R，输入 cmd，打开命令提示符

2. 进入项目目录：
   cd D:\农产品追溯系统

3. 执行停止命令：
   docker-compose down

--------------------------------------------------------------------------------
步骤 4.3：完全清理（可选）
--------------------------------------------------------------------------------

如果您想完全清理系统（删除所有数据），可以执行：

1. 打开命令提示符

2. 进入项目目录

3. 执行以下命令：
   docker-compose down -v

这会删除所有容器和数据卷，下次启动需要重新初始化。

================================================================================
                        第六部分：常见问题解答
================================================================================

--------------------------------------------------------------------------------
问题 1：双击"启动.bat"后闪退
--------------------------------------------------------------------------------

【可能原因】
- Docker Desktop 未运行
- Python 未安装或未添加到 PATH

【解决方法】
1. 确保 Docker Desktop 已启动（任务栏图标为绿色）
2. 确保 Python 已正确安装
3. 右键"启动.bat"，选择"编辑"，在最后添加一行：pause
4. 保存后重新运行，可以看到错误信息

--------------------------------------------------------------------------------
问题 2：提示"Docker 未运行"
--------------------------------------------------------------------------------

【解决方法】
1. 双击桌面的 Docker Desktop 图标
2. 等待 1-3 分钟，直到任务栏图标变绿
3. 重新运行"启动.bat"

--------------------------------------------------------------------------------
问题 3：Docker 镜像下载很慢或失败
--------------------------------------------------------------------------------

【解决方法：配置国内镜像加速】

1. 右键点击任务栏的 Docker 图标
2. 选择"Settings"（设置）
3. 点击左侧的"Docker Engine"
4. 在右侧的 JSON 配置中，添加以下内容：

{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn",
    "https://hub-mirror.c.163.com",
    "https://mirror.baidubce.com"
  ]
}

5. 点击"Apply & Restart"应用并重启
6. 重新运行"启动.bat"

--------------------------------------------------------------------------------
问题 4：提示端口被占用
--------------------------------------------------------------------------------

【可能被占用的端口】
- 5000：Flask Web 应用
- 3307：MySQL
- 9870：Hadoop NameNode
- 10000：HiveServer2
- 8080：Spark Master

【解决方法】
1. 找出占用端口的程序：
   打开命令提示符，输入：netstat -ano | findstr :5000
   
2. 记下最后一列的 PID（进程ID）

3. 打开任务管理器（Ctrl + Shift + Esc）

4. 点击"详细信息"标签

5. 找到对应 PID 的进程，右键结束任务

6. 重新启动系统

--------------------------------------------------------------------------------
问题 5：浏览器访问 localhost:5000 显示无法访问
--------------------------------------------------------------------------------

【解决方法】
1. 确认命令行窗口中显示"Running on http://127.0.0.1:5000"
2. 尝试访问 http://127.0.0.1:5000（用 127.0.0.1 代替 localhost）
3. 检查防火墙是否阻止了访问
4. 尝试关闭杀毒软件后重试

--------------------------------------------------------------------------------
问题 6：页面显示但数据为空
--------------------------------------------------------------------------------

【解决方法】
系统默认使用模拟数据，如果数据为空：
1. 检查 flask_app/db_service.py 文件是否存在
2. 重启 Flask 应用
3. 清除浏览器缓存后刷新页面

--------------------------------------------------------------------------------
问题 7：Hive 容器启动失败
--------------------------------------------------------------------------------

【查看错误日志】
1. 打开命令提示符
2. 输入：docker logs hive-server
3. 查看错误信息

【常见解决方法】
1. 删除旧数据重新启动：
   docker-compose down -v
   docker-compose up -d --build

2. 等待更长时间（Hive 初始化较慢）

--------------------------------------------------------------------------------
问题 8：电脑内存不足
--------------------------------------------------------------------------------

【症状】
- 系统运行缓慢
- Docker 容器频繁重启
- 电脑卡顿

【解决方法】
1. 关闭其他不必要的程序
2. 减少 Docker 内存限制：
   - 打开 Docker Desktop 设置
   - 点击 Resources -> Advanced
   - 将 Memory 调整为 4GB
   - 点击 Apply & Restart

附录 A：Windows 家庭版处理方法
--------------------------------------------------------------------------------

Windows 家庭版默认不支持 Hyper-V，但可以使用 WSL 2 运行 Docker。

【步骤】

1. 以管理员身份打开 PowerShell：
   - 右键点击开始菜单
   - 选择"Windows PowerShell（管理员）"

2. 执行以下命令启用 WSL：
   dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart

3. 执行以下命令启用虚拟机平台：
   dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

4. 重启电脑

5. 下载并安装 WSL 2 内核更新包：
   https://aka.ms/wsl2kernel

6. 设置 WSL 2 为默认版本：
   打开 PowerShell，执行：wsl --set-default-version 2

7. 安装 Docker Desktop，安装时选择"Use WSL 2 instead of Hyper-V"
